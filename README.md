# SíChef website

Official marketing website for SíChef, serving Barcelona.

## Hosting

Publish with GitHub Pages from `main` / root. Custom domain: `sichef.es` (declared in `CNAME`). No build step or dependencies are required.

## Editing

- `index.html`: customer homepage
- `for-chefs/index.html`: chef features and signup
- `privacy/index.html`, `terms/index.html`: legal pages
- `style.css`, `app.js`: styling and interactions
- `assets/`: original app screenshots and brand/food images

Chef signup links use the Airtable form. Customer links open the SíChef customer app. App screenshots are original captures.
